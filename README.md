# The Deep

The Deep is an immersive, scroll-driven web experience that takes the user on a vertical journey through the ocean — from sun-drenched shallow waters all the way down to the crushing darkness of the abyssal zone. The project blends storytelling with interactive design, turning passive scrolling into an act of underwater exploration.
The concept was inspired by the way depth transforms everything — light, colour, pressure, and life. Each scroll section corresponds to a distinct oceanic layer: the sunlit epipelagic zone, the twilight mesopelagic, the midnight bathypelagic, and finally the hadal abyss. Visual and atmospheric changes accompany each transition, immersing the user in the character of each zone.
The design process began with establishing a strong visual language rooted in deep-sea aesthetics — dark, desaturated palettes punctuated by bioluminescent accents, fluid motion, and subtle particle effects that evoke the sensation of drifting through water. Typography and layout were kept minimal to let the environment do the storytelling.
Technically, The Deep is built with React and TypeScript, using Vite as the build tool and Tailwind CSS for styling. Scroll-driven animations are choreographed to create smooth, cinematic transitions between zones, with each section carefully timed to feel like a natural descent rather than a page change.
The project sits at the intersection of interactive design and environmental storytelling — a reminder of how much of our own planet remains unexplored, alien, and awe-inspiring.
## Getting Started

Install dependencies:
```bash
bun install
```

Run the development server:
```bash
bun dev
```

Build for production:
```bash
bun run build
```

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
