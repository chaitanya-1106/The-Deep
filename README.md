# The Deep

A web application built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

Install dependencies:
```bash
bun install
```

Run the development server:
```bash
bun dev
```

Build for production:
```bash
bun run build
```

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
